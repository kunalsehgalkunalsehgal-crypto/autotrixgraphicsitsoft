DIRECT RUN
1. Unzip.
2. Open index.html in Chrome, Edge, Firefox or Safari.
3. All images are included in assets/. No build or install needed.

ADD ONLY THESE THREE SECTIONS TO YOUR EXISTING STEP 7 CODE
1. Paste the contents of process.html, reviews.html and faq.html (in that order)
   immediately before </main> in your current index.html.
2. Paste steps8-10.css at the END of your current style.css.
3. Paste steps8-10.js at the END of your current script.js.
4. No new images and no external libraries are needed for these sections.

WORKING INTERACTIONS
- Process cards rise on scroll, icons react on hover and the progress line fills.
- Reviews slide with next/previous buttons, dots, Left/Right keys, and touch swipes.
- FAQ opens one answer at a time with animated expansion/collapse.
- Layout uses responsive breakpoints, reduced-motion support, accessible labels.
- If JavaScript is disabled, the three sections still display readable content.
