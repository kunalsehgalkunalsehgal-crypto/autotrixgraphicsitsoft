AUTOTRIX SIGNS & GRAPHICS | STEP 6 + 7

STEP 6: Custom Signs & Graphics (6 large image service cards, hover animation, inquiry links).
STEP 7: Our Work (5 demo image gallery cards, animated entry, category filters and keyboard-friendly image lightbox).

TO RUN
1. Extract this ZIP.
2. Open index.html in a browser. No install, server or API needed.
3. Image assets are local in assets/.

TO ADD ONLY NEW SECTIONS TO YOUR CURRENT STEP 5 PROJECT
1. Copy contents of graphics-services.html and our-work.html before closing </main> in your current index.html.
2. Paste sections.css at the very END of style.css.
3. Paste sections.js at the very END of script.js.
4. Copy only newly added images from this ZIP assets/ into existing assets/ (do not overwrite existing assets).

TESTABLE FUNCTIONS
- All service cards open a service-specific email inquiry.
- Gallery tabs filter images; all example cards open larger previews.
- Close by X, Escape or outside click; Left/Right keys switch images.
- All content remains visible if scroll-reveal JS cannot run.
- prefers-reduced-motion is respected.
